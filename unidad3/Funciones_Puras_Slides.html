Momento 3 · El tema nuevo

Una función es pura si…

Regla 1

Con los mismos argumentos, siempre regresa lo mismo.

Regla 2

No cambia nada fuera de ella: no imprime, no pide, no modifica variables de afuera.

[0:30] 🎙 «Como una calculadora: si tecleas 2 + 2, siempre da 4, y la calculadora no te cambia nada más en el mundo. Eso es una función pura».

🎙 «Si una función hace algo hacia afuera, imprimir, pedir datos, cambiar una variable global, decimos que tiene efectos secundarios».

Momento 3 · Con sus propias funciones

¿Pura o no? ¿Por qué?

✍ Decide antes de que se revele

def con_iva(monto):
    return round(monto * 1.16, 2)

✓ Pura: 376 → siempre 436.16.

def pedir_edad():
    return int(input("Edad: "))

✗ No: depende de lo que teclee el usuario.

def muestra_total(monto):
    print(monto * 1.16)

✗ No: imprime en vez de regresar.

def consejo(kwh):
    if kwh <= 150:
        return "Vas bien"
    return "Cuidado"

✓ Pura: regresa un texto; no lo imprime.

iva = 0.16

def con_iva(monto):
    return monto * (1 + iva)

✗ No: depende de iva, que vive afuera.

def agrega(lista, x):
    lista.append(x)
    return lista

✗ No: modifica la lista de quien la llamó.

Una por una: lee la función, pide que voten con la mano (pura / no pura) y revela.

La quinta: «Si alguien cambia iva a 0.08 en otra parte del programa, la misma llamada con 100 regresa otra cosa. Rompe la regla 1». La sexta: «la lista que mandaste ya no es la misma después de llamar a la función. Rompe la regla 2».

Momento 3 · Ámbito

Lo que nace dentro de una función, se queda adentro

def cuenta_digitos(texto):
    contador = 0
    for c in texto:
        if c >= "0" and c <= "9":
            contador = contador + 1
    return contador


n = cuenta_digitos("Hola2024")
print(n)          # 4
print(contador)   # ?

⏸ ¿Qué imprime la última línea?

print(contador)NameError: name 'contador' is not defined

contador es local: existe solo mientras la función trabaja. Afuera solo llega lo que se regresa con return.

🎙 «La variable contador nace cuando se llama a la función y desaparece cuando termina. Desde afuera no se puede ver. Lo único que sale es lo que entregamos con return, que aquí guardamos en n».

🎙 «Esto es una ventaja: cada función tiene su propio cuarto. Pueden tener cinco funciones con una variable contador cada una y no se mezclan».

Momento 3 · La trampa

Una lista que recibes no es tuya

✗ Modifica la de afuera

def agrega_simbolo(faltan):
    faltan.append("un símbolo")
    return faltan

mia = ["un dígito"]
nueva = agrega_simbolo(mia)
print(mia)
['un dígito', 'un símbolo']

La lista original cambió: la función tocó algo que no era suyo.

✓ Crea una nueva

def agrega_simbolo(faltan):
    nueva = faltan + ["un símbolo"]
    return nueva

mia = ["un dígito"]
nueva = agrega_simbolo(mia)
print(mia)
print(nueva)
['un dígito'] ['un dígito', 'un símbolo']

La original queda igual; la función regresa una lista nueva.

🎙 «Con números no pasa, pero con listas sí: si la función hace append sobre la lista que recibió, cambia la lista de quien la llamó. Es un efecto secundario escondido».

🎙 «Por eso que_falta, la de hoy, crea su propia lista vacía adentro, la llena y la regresa. No toca nada de afuera».

Momento 4 · Construir · ahora sí, abre la computadora

Un texto es una fila de caracteres

H0o1l2a324052647

Para contar dígitos, revisamos uno por uno: ¿este carácter es un dígito? Si sí, sumamos 1.

¿Cómo sabe la computadora que es un dígito? Los caracteres tienen orden: "0" <= c <= "9", "A" <= c <= "Z". Funciona igual en Python y en JavaScript.

[0:50] 🎙 «Un texto es como una lista de letras. "Hola2024" tiene 8 caracteres, del 0 al 7. Contar dígitos es lo mismo que contar aprobados en una lista: recorrer y preguntar».

🎙 «Python tiene isdigit() y JavaScript tiene otras formas, pero comparar con "0" y "9" funciona en casi cualquier lenguaje. Nos quedamos con la lógica, no con el truco del lenguaje».

Momento 4 · Del pseudocódigo a Python

Cada renglón del pseudocódigo, una línea

def cuenta_digitos(texto):
    contador = 0
    for c in texto:
        if c >= "0" and c <= "9":
            contador = contador + 1
    return contador

Nombre y parámetro, como dice el contrato.

contador ← 0: variable local.

para cada c en texto: el for recorre carácter por carácter.

si es dígito, suma 1.

regresar: fuera del for, cuando ya se revisaron todos.

Momento 4 · El patrón se repite

Solo cambia la pregunta

def cuenta_digitos(texto):
    contador = 0
    for c in texto:
        if c >= "0" and c <= "9":
            contador = contador + 1
    return contador
def cuenta_mayusculas(texto):
    contador = 0
    for c in texto:
        if c >= "A" and c <= "Z":
            contador = contador + 1
    return contador
def cuenta_simbolos(texto):
    contador = 0
    for c in texto:
        if c in SIMBOLOS:
            contador = contador + 1
    return contador

Para los símbolos usamos SIMBOLOS = "!@#$%&*?.-_" y preguntamos c in SIMBOLOS: ¿c está en esa lista de caracteres?

🎙 «Pausa: escriban ustedes cuenta_mayusculas y cuenta_simbolos antes de que las muestre». Al revelar, se iluminan las líneas que cambian: la condición del if.

🎙 «SIMBOLOS está afuera de las funciones y nunca cambia: es una constante, por eso va en mayúsculas. Usar una constante no rompe la pureza, porque su valor nunca cambia».

Momento 4 · Las piezas se combinan

Funciones que usan funciones

def es_segura(texto):
    return (len(texto) >= 8 and cuenta_mayusculas(texto) > 0
            and cuenta_digitos(texto) > 0 and cuenta_simbolos(texto) > 0)
def que_falta(texto):
    faltan = []
    if len(texto) < 8:
        faltan.append("al menos 8 caracteres")
    if cuenta_mayusculas(texto) == 0:
        faltan.append("una mayúscula")
    if cuenta_digitos(texto) == 0:
        faltan.append("un dígito")
    if cuenta_simbolos(texto) == 0:
        faltan.append("un símbolo")
    return faltan
"Colima2026"→largo 10 ✓ · mayúsculas 1 ✓ · dígitos 4 ✓ · símbolos 0 ✗→False · ["un símbolo"]

🎙 «es_segura une las cuatro preguntas con and: basta que una falle para que todo sea False. que_falta crea su propia lista vacía, agrega lo que no se cumple y la regresa. Las dos son puras».

Momento 4 · Mismo contrato, otras palabras

cuenta_digitos en Python y en JavaScript

def cuenta_digitos(texto):
    contador = 0
    for c in texto:
        if c >= "0" and c <= "9":
            contador = contador + 1
    return contador
function cuenta_digitos(texto) {
  let contador = 0;
  for (const c of texto) {
    if (c >= "0" && c <= "9") {
      contador = contador + 1;
    }
  }
  return contador;
}

La comparación "0" <= c <= "9", el contador y el return son idénticos. Cambian let, for…of, && y las llaves.

🎙 «Como en la línea de ensamble: el contrato es el mismo. Si entendieron la lógica, la traducción es casi mecánica».
