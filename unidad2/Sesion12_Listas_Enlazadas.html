TEMA 9 · COMPARACIÓN

La misma lista, dos formas de vivir en memoria

ARREGLO (Sesión 11): casillas JUNTAS
"manzana"1000
"pera"1008
"uva"1016
LISTA ENLAZADA (hoy): casillas DISPERSAS, unidas por direcciones
"manzana"1000 · sig: 3400
"pera"3400 · sig: 2200
"uva"2200 · sig: None

Las direcciones 1000, 3400, 2200 no siguen ningún orden: cada nodo vive donde hubo espacio, y la dirección guardada en sig lo conecta con el siguiente.

⏸ PREDICE ANTES DE EJECUTAR

Se olvidó revisar el final de la cadena. ¿Qué pasa?

🐍 Python
actual = cabeza
while True:
    print(actual.valor)
    actual = actual.siguiente
🟨 JavaScript
let actual = cabeza;
while (true) {
  console.log(actual.valor);
  actual = actual.siguiente;
}
