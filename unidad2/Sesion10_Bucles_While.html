TEMA 7 · PATRÓN CLAVE

El patrón centinela — parar cuando el usuario lo decide

Un centinela es un valor especial que le indica al programa "detente aquí" — el usuario lo escribe cuando ya no quiere seguir.

SUMAR NÚMEROS HASTA QUE EL USUARIO ESCRIBA -1
total = 0
numero = int(input("Número (-1 para salir): "))
while numero != -1:
  total += numero
  numero = int(input("Número (-1 para salir): "))
print("Suma:", total)

💡 Nota que input() aparece dos veces: una antes del while (para tener algo que evaluar la primera vez) y otra dentro (para actualizar y eventualmente cumplir la condición de salida). -1 es tu centinela — el mismo patrón que usarás en el Reto Final de esta unidad.

TEMA 7 · CONCEPTO NUEVO

while True + break — ejecutar al menos una vez

Python no tiene "do-while" como otros lenguajes — pero while True + break logra exactamente lo mismo.

CÓDIGO
while True:
  resp = input("¿Seguir? (s/n): ")
  if resp == "n":
    break
  print("Continuando...")

while True siempre es True — el bucle jamás terminaría solo

break es la única salida — corta el bucle inmediatamente al ejecutarse

Garantiza que el bloque se ejecute al menos una vez antes de poder salir

TEMA 7 · CÓMO DECIDIR

¿for o while? Una sola pregunta

¿Sabes cuántas veces se va a repetir antes de empezar?

Sí → for
  • ✓ La tabla del 1 al 10
  • ✓ Revisar las 5 calificaciones de una lista
  • ✓ Cada letra de un texto
No → while
  • ✓ Pedir la contraseña hasta que acierte
  • ✓ Capturar calificaciones hasta que escriba -1
  • ✓ Repetir la pregunta hasta que responda si o no
CON for — 2 LÍNEAS
for i in range(1, 4): print(i)
MISMO RESULTADO CON while — TÚ CUIDAS EL CONTADOR
i = 1 while i < 4: print(i) i += 1 ← si la olvidas: infinito
