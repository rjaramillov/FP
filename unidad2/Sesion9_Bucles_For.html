print("Hola 1")
print("Hola 2")
print("Hola 3")
print("Hola 4")
print("Hola 5")
✓ CON BUCLE for — HOY
for i in range(1, 6):
  print(f"Hola {i}")

Mismo resultado. 2 líneas en vez de 5 — y funciona igual de bien para 5 repeticiones que para 5 millones.

TEMA 7 · CONCEPTO BASE

for i in range() — la anatomía

for i in range(5):
    print(i)
🖱️ HAZ CLIC EN CADA PARTE PARA VER SU EXPLICACIÓN A FONDO

💡 i toma, uno por uno, cada valor de range(5): primero 0, luego 1, 2, 3, 4 — y el bucle termina. El bloque con sangría se ejecuta una vez por cada valor.

TEMA 7 · CONCEPTO NUEVO

for también recorre listas y texto directamente

No siempre necesitas range() — for puede recorrer una lista o un texto directamente, uno por uno.

RECORRER UNA LISTA
frutas = ["manzana", "pera", "uva"]
for fruta in frutas:
  print(fruta)
RECORRER UN TEXTO
palabra = "sol"
for letra in palabra:
  print(letra)

✓ En ambos casos, la variable de control (fruta, letra) toma cada elemento de la secuencia, en orden, uno por iteración.
