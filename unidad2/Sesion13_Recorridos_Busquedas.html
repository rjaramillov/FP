TEMA 10 · LA MISMA BÚSQUEDA, YA INCLUIDA

Python y JavaScript ya saben buscar… pero avisan distinto

🐍 Python
🟨 JavaScript
¿Está?
10 in califsTrue
califs.includes(10)true
¿En qué posición?
califs.index(10)3
califs.indexOf(10)3
¿Y si NO está?
califs.index(4)?
califs.indexOf(4)?

JavaScript usa la misma convención que nuestro pos = -1. Python prefiere detener el programa con ValueError: por eso, en Python, primero se pregunta if 4 in califs:. Y ojo: por dentro, los dos hacen una búsqueda secuencial, igual que la que acabas de ver.
