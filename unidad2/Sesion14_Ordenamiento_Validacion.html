⏸ PREDICE ANTES DE EJECUTAR

Los dos lenguajes ya traen sort()… ¿ordenan igual?

🐍 Pythonsorted([10, 9, 1])[1, 9, 10]
🟨 JavaScript[10, 9, 1].sort()?

Sin instrucciones, JavaScript convierte los números a texto y los ordena como en el diccionario, letra por letra: "1" < "10" < "9", porque compara primero el 1 contra el 9.

[10, 9, 1].sort((a, b) => a - b)[1, 9, 10]

La «receta» (a, b) => a - b le dice: compáralos como números. Por eso vale la pena saber cómo ordena un algoritmo por dentro: las funciones ya hechas también pueden sorprenderte.

TEMA 11 · PRINCIPIO DE SEGURIDAD

Nunca confíes en lo que escribe el usuario: repite hasta que sea válido

🐍 Python
cal = float(input("Calificación: "))
while cal < 0 or cal > 10:
    print("Fuera de rango")
    cal = float(input("Calificación: "))
print("Aceptada:", cal)
🟨 JavaScript
let cal = Number(prompt("Calificación:"));
while (cal < 0 || cal > 10 || Number.isNaN(cal)) {
  console.log("Fuera de rango");
  cal = Number(prompt("Calificación:"));
}
console.log("Aceptada:", cal);

Es el while de la Sesión 10 con el rango de un if. Si escriben «hola»: Python truena con ValueError; JavaScript obtiene NaN («no es un número») y hay que revisarlo con Number.isNaN().

TEMA 11 · SÍNTESIS

Dos caminos, mismo destino

SELECCIÓN

Busca el mínimo en todo lo que falta cada vez — muchas comparaciones, pocos intercambios.

Fácil de entender y explicar — buena para aprender el concepto.

INSERCIÓN

Solo compara con la parte ya ordenada — si la lista casi ya está ordenada, es muy rápida.

Se parece más a cómo ordenas cosas en la vida real.

💡 Python tiene su propia función sorted() que ordena mucho más rápido que ambas — pero entender selección e inserción te enseña cómo piensa un algoritmo de ordenamiento por dentro.
