TEMA 4 · CONCEPTO BASE

Variables — cajas con nombre

Una variable es un espacio con nombre donde Python guarda un valor. A diferencia del pseudocódigo, no declaras el tipo — Python lo detecta solo.

REGLAS PARA NOMBRAR VARIABLES
✓Empieza con letra o guion bajo: edad, _total
✓Puede tener letras, números y guiones bajos: nota_1
✗No puede empezar con número: 1nota ✗
✗No puede tener espacios: nota final ✗
LA VARIABLE PUEDE CAMBIAR DE VALOR
nota = 8
print(nota) # 8
nota = 9.5
print(nota) # 9.5

👀 La misma variable nota primero fue int (8) y después float (9.5). En Python, el tipo lo define el valor actual, no el nombre de la variable.

TEMA 4 · EL PROBLEMA RESUELTO

Conversión de tipos (casting)

4 funciones para convertir un valor de un tipo a otro:

int()

Convierte a entero

int("20") → 20
float()

Convierte a decimal

float("9.5") → 9.5
str()

Convierte a texto

str(20) → "20"
bool()

Convierte a booleano

bool(0) → False
RESOLVIENDO EL PROBLEMA DE SESIÓN 4 — PASO A PASO
edad_texto = input("Edad: ") # str, ej: "20"
edad_numero = int(edad_texto) # ahora es int: 20
print(edad_numero + 5) # 25 — ¡ya funciona!

TEMA 4 · CONVENCIÓN

Constantes — valores que no deberían cambiar

Python no tiene constantes reales — técnicamente, cualquier variable puede cambiar. Pero existe una convención universal: escribir en MAYÚSCULAS las variables que representan valores fijos.

💡 Es una señal para otros programadores (y para ti mismo): "no cambies este valor". Python no lo impide técnicamente, pero romper esta convención se considera mala práctica.

EJEMPLO — CONSTANTES VS VARIABLES
# Constantes — MAYÚSCULAS
IVA = 0.16
MAX_INTENTOS = 3
# Variables — minúsculas
precio = 100
total = precio * (1 + IVA)

👀 IVA no debería cambiar durante el programa — por eso va en mayúsculas. precio y total sí cambian, por eso van en minúsculas.

TEMA 4 · ERROR DE EJECUCIÓN

ValueError — cuando la conversión no es posible

Recuerda de Sesión 4: este es un error de ejecución — la estructura del código es correcta, pero se cae a medias.

🔴
CÓDIGO QUE FALLA
edad = input("Edad: ")
edad = int(edad)

Si el usuario escribe "veinte" en vez de "20":

ValueError: invalid literal for int()

🟢
POR QUÉ PASA

int() solo puede convertir texto que parezca un número. Si el texto tiene letras, espacios raros o símbolos, Python no sabe cómo convertirlo.

✓ int("20") funciona

✗ int("veinte") falla

💡 En programas reales, esto se maneja con validación de datos — lo veremos en la Sesión 6.
