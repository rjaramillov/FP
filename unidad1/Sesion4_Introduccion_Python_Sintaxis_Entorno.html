⚠ El cambio más importante: en pseudocódigo cerrabas cada bloque escribiendo FIN SI. En Python no existe esa palabra — el bloque se cierra con la sangría (indentación). Si la línea está recorrida hacia la derecha, pertenece al bloque de arriba. Si no, ya salió de él.

TEMA 3 · OTRA SORPRESA ANTES DE EMPEZAR

Python no grita, y no habla español

TU PSEUDOCÓDIGO
SI ... ENTONCES
PARA i DESDE 1 HASTA 10
MIENTRAS x < 10
PYTHON REAL
if ...:
for i in range(1,11):
while x < 10:

💡 Python usa palabras en inglés y en minúsculas. SI no existe — es if. Python además distingue mayúsculas de minúsculas: If o IF tampoco funcionan.

TEMA 3 · ANTES DE ESCRIBIR CÓDIGO

¿Qué es una variable? — la caja con etiqueta

Tiene un nombre — así te refieres a ella (en el ejemplo, "edad")

Guarda un valor — lo que hay adentro de la caja ahora mismo

El valor se puede reemplazar — la caja no crece, solo cambia lo que contiene

El error más común: pensar que la variable es el valor. No — la variable contiene el valor, y puede contener otro después.

TEMA 3 · UNA CONFUSIÓN COMÚN

¿Por qué esto NO es una ecuación?

✗ EN MATEMÁTICAS
x = x + 1

No tiene solución. Es una ecuación imposible.

✓ EN PROGRAMACIÓN
x ← x + 1

Toma el valor actual de x, súmale 1, guarda el resultado en x otra vez.

💡 La flecha ← nunca es "es igual a". Siempre léela como "guarda en" — igual que el = que verás en Python en un momento.

Estructura básica de un programa

Python ejecuta tu programa de arriba hacia abajo, línea por línea, en el orden exacto en que las escribiste.

#
Comentarios

Empiezan con # — Python los ignora. Sirven para explicar tu código a otros (o a ti mismo en el futuro)

↓

""

TEMA 3 · ENTRADA DE DATOS

input() — el programa cobra vida

La función input() pausa el programa y espera a que el usuario escriba algo y presione Enter.

nombre = input("¿Cómo te llamas? ")
print("Hola, " + nombre)

⚠ Dato clave: todo lo que input() captura es siempre texto (str) — incluso si el usuario escribe un número. Si necesitas hacer cálculos, hay que convertirlo. Lo veremos a fondo en la Sesión 5.
