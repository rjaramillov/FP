📌 RECORDATORIO RÁPIDO — SESIONES 7-8
if / elif / else

Python revisa en orden y ejecuta solo la primera condición True — se detiene ahí.

anidación

Un if dentro de otro if solo se evalúa si el de afuera fue True — otro salto de sangría.

and / or

Combinan condiciones dentro de un mismo if sin necesidad de anidar.
