TEMA 6 · CONCEPTO BASE

if — la decisión más simple

Ejecuta un bloque de código solo si una condición es True. Si es False, el bloque simplemente se salta.

LA ANATOMÍA DE UN if
if edad >= 18:
    print("Mayor de edad")
if — palabra clave obligatoria
edad >= 18 — la condición (debe evaluar a bool)
: — dos puntos, nunca se olvida
sangría — el bloque que se ejecuta si es True
MISMA LÓGICA, DOS FORMAS
PSEUDOCÓDIGO (SESIÓN 3)
SI edad ≥ 18
  ESCRIBIR
  "Mayor"
FIN SI
PYTHON (HOY)
if edad >= 18:
  print(
  "Mayor")

TEMA 6 · CONCEPTO BASE

if / else — cubriendo las dos ramas

Cuando quieres una acción para True y otra distinta para False, agregas else.

if calificacion >= 6:
    print("Aprobado")
else:
    print("Reprobado")
calificacion = 8
La condición 8 >= 6 es True → se ejecuta el bloque de if → imprime "Aprobado"
calificacion = 4
La condición 4 >= 6 es False → se ejecuta el bloque de else → imprime "Reprobado"

💡 Siempre se ejecuta exactamente una de las dos ramas — nunca ambas, nunca ninguna.

TEMA 6 · CONCEPTO NUEVO

if / elif / else — más de dos caminos

Cuando hay más de dos posibles caminos, encadenas condiciones con elif (viene de "else if").

CLASIFICADOR DE CALIFICACIÓN
if nota >= 90:
  print("A")
elif nota >= 80:
  print("B")
elif nota >= 70:
  print("C")
else:
  print("F")

Python revisa en orden: primero if, luego cada elif. En cuanto encuentra una condición True, ejecuta ese bloque y se detiene — ignora todo lo demás.

⚠ No existe else if en Python (a diferencia de otros lenguajes). La palabra exacta es elif, una sola palabra.

💡 Solo puede haber un if y un else (opcional), pero cuantos elif necesites en medio.
