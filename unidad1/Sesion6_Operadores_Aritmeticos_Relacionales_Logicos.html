TEMA 5 · CONCEPTO BASE

Operadores relacionales — comparar valores

Comparan dos valores y siempre devuelven un bool: True o False.

==

igual a

!=

diferente de

>

mayor que

<

menor que

>=

mayor o igual

<=

menor o igual

⚠ Error clásico: = asigna un valor. == compara dos valores. Son símbolos distintos con funciones completamente distintas.

EJEMPLOS EN CONSOLA
print(5 == 5) # True
print(5 != 3) # True
print(10 > 7) # True
print(10 < 7) # False
print("Ana" == "ana") # False
VISUALIZANDO 10 > 7 EN LA RECTA NUMÉRICA

TEMA 5 · COMBINANDO CONDICIONES

Operadores lógicos — haz clic para probar

and

Verdadero solo si ambas condiciones lo son

A and B → True
or

Verdadero si al menos una lo es

A or B → True
not

Invierte el valor — lo opuesto

not A → False
EJEMPLO CON AND — VALIDAR ACCESO
edad = 20
tiene_permiso = True
if edad >= 18 and tiene_permiso:
  print("Acceso permitido")
EJEMPLO CON OR — MÚLTIPLES DESCUENTOS
es_estudiante = False
es_adulto_mayor = True
if es_estudiante or es_adulto_mayor:
  print("Aplica descuento")

TEMA 5 · ORDEN DE EVALUACIÓN

Precedencia — ¿qué se calcula primero?

ORDEN DE MAYOR A MENOR PRIORIDAD
1 ( ) paréntesis
2 ** potencia
3 * / // % mult. y división
4 + - suma y resta
5 == != > < >= <= relacionales
6 not and or lógicos (al final)
✗ SIN PARÉNTESIS — CONFUSO
2 + 3 * 4 → 14

Multiplica primero (3*4=12), luego suma (2+12=14)

✓ CON PARÉNTESIS — CLARO
(2 + 3) * 4 → 20

Cuando tengas duda, usa paréntesis
