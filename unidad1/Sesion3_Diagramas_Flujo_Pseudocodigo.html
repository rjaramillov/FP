TEMA 2 · CONCEPTO BASE

Pseudocódigo estandarizado

El pseudocódigo es lenguaje natural estructurado: no tiene la sintaxis exacta de un lenguaje de programación, pero sigue reglas fijas de formato.

VERBOS DE ACCIÓN ESTÁNDAR
INICIO / FIN

delimitan el algoritmo

LEER

captura un dato

ESCRIBIR

muestra un resultado

SI / SINO

toma una decisión

PARA

repite N veces

MIENTRAS

repite con condición

REGLAS DE FORMATO (Gaddis, 2021)
1Una instrucción por línea — nunca dos en la misma
2Palabras clave en MAYÚSCULAS (INICIO, SI, PARA...)
3La sangría muestra qué pertenece a cada bloque
4Los comentarios inician con // y no se ejecutan
EJEMPLO 1 — DECISIÓN (SI / SINO)
INICIO
  LEER edad
  SI edad ≥ 18 ENTONCES
    ESCRIBIR "Mayor de edad"
  SINO
    ESCRIBIR "Menor de edad"
  FIN SI
FIN
EJEMPLO 2 — REPETICIÓN (PARA)
INICIO
  PARA i DESDE 1 HASTA 5
    ESCRIBIR i
  FIN PARA
FIN
Imprime: 1 2 3 4 5 — una línea por cada vuelta del PARA

TEMA 2 · BUENAS PRÁCTICAS

Errores comunes al diagramar

✗
DECISIÓN SIN RAMA "NO"

Si el saldo NO es mayor a 0 — ¿qué hace el programa? Nadie lo sabe. Toda decisión necesita sus 2 caminos.

✓
DECISIÓN CON AMBAS RAMAS

Ambos caminos (Sí / No) tienen una acción clara. El diagrama es completo y sin ambigüedad — cumple FPE.
