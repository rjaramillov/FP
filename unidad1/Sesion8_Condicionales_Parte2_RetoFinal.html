PARA ARRANCAR

Un if dentro de otro if.

if edad >= 18:
  if tiene_id:
    print("Acceso completo")

El if de adentro solo se evalúa si el if de afuera fue True. Es como pasar por dos filtros seguidos.

TEMA 6 · CONCEPTO NUEVO

Cómo se anida — la regla es la sangría

Cada nivel de anidación agrega otro salto de sangría — 4 espacios más por cada if dentro de otro.

if promedio >= 8: ← nivel 1
  if asistencia >= 90: ← nivel 2
    print("Beca completa")
  else:
    print("Beca parcial")

💡 El else del nivel 2 pertenece al if asistencia — Python sabe a cuál if corresponde cada else según su nivel de sangría.
